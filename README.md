# Nivara - Tienda en Línea para Desarrolladores

Este proyecto es una página web de práctica para una tienda en línea ficticia llamada Nivara.

## Descripción

Nivara es un sitio web estático que simula una tienda en línea de ropa temática para desarrolladores. El proyecto incluye múltiples páginas como inicio, tienda, producto individual y una página "acerca de".

## Características

- Diseño responsivo
- Página de inicio con productos destacados
- Catálogo de productos
- Página de producto individual
- Información sobre la empresa

## Tecnologías Utilizadas

- HTML5
- CSS3
- Fuentes de Google (Staatliches)
